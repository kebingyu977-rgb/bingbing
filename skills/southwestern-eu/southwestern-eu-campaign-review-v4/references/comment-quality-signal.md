# 评论结构分析 — KOL内容质量信号

## 为什么看评论结构
eCPM和ER只衡量"看的人多不多、互不互动"，但**不看的人会不会买**。评论结构揭示：
- 粉丝画像是否与目标用户匹配（无关评论占比）
- 内容是否触发真实购买意图（购买意愿占比）
- 卖点是否传达成功（功能讨论占比）

## 标签定义
| 标签 | 优质目标 | 低质量信号 |
|------|---------|-----------|
| 产品购买意愿 | ≥15% | <10% = 内容/粉丝画像不匹配 |
| 产品功能 | ≥5% | <2% = 卖点未传达 |
| 品牌认可 | ≥3% | <1% = 品牌植入失败 |
| 产品使用场景 | ≥3% | <2% = 场景共鸣不足 |
| 负面评价 | <5% | >10% = 内容引发抵触 |
| 无关评论 | <60% | >80% = 粉丝画像严重不匹配 |

## IT Round 1实测（教训）
- 购买意愿: 7.3%（严重偏低，目标≥15%）
- 无关评论: 80.7%（粉丝画像不匹配）
- 功能讨论: 4.6%（勉强达标）
- 品牌认可: 3.2%（达标）
- 负面评价: 1.4%（良好）

**诊断**：KOL粉丝不是目标用户（家清/洗地机购买者），而是刷流量型观众。Home-decor类型KOL虽然匹配家居场景但ER最低（0.3%）。Family类型ER相对较高但购买意愿偏低。

## 提取方法
从Excel"评论汇总"sheet读取，统计每条评论的标签列分布。
