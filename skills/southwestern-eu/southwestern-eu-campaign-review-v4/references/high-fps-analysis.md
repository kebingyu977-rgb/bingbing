# 高频帧分析管线 V4 (2fps)

## 为什么从0.5fps升级到2fps

关键动作（折叠演示/CTA尾帧/卖点画面）通常仅持续2-3秒。
0.5fps = 每2秒1帧 → 30秒视频仅15帧 → **极易漏检关键瞬间**。
2fps = 每0.5秒1帧 → 30秒视频60帧 → 覆盖全部关键动作。

## 抽帧命令

```bash
ffmpeg -i '/tmp/video_N.mp4' -vf "fps=2,scale=640:-1:flags=lanczos" /tmp/frames_N/frame_%04d.jpg -y
```

## 分析流程

1. **密集抽帧**：2fps提取全部帧（30秒=60帧）
2. **逐帧扫描**：每帧调用vision_analyze分析画面内容
3. **语义分组**：按时间段合并相邻帧的相同内容（如0-3秒都是同一个动作）
4. **标注时间线**：记录每个卖点的起止秒数
5. **计算产品露出占比**：有产品出现的帧数 ÷ 总帧数
6. **生成HTML**：每个视频一个时间线卡片

## HTML输出格式

每条视频一个卡片，包含：
- 标题行：`达人名称 | 时长 | 评级 | 预算`
- 时间线表格：时间段 | 画面内容 | 字幕 | 卖点验证
- 总结行：展示卖点数 | 产品露出占比 | 核心问题

## 管理层讨论处理

⚠️ **铁律**：管理层提出的策略讨论问题（如"30秒能不能讲清产品"）**仅**在对话中讨论，不写入HTML报告。报告保持纯净的复盘结论+数据。
