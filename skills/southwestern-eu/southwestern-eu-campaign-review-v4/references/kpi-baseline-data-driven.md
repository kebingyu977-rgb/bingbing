# KPI基准线数据驱动生成方法 — 三国统一版（2026-07-23定稿）

## 核心原则
用真实投放数据分布(P25/P50/P75百分位)生成KPI阈值，**拒绝Agency自定的宽松线**。

**推导逻辑**：
- FR 8场79条有效placement是唯一有数据支撑的基准
- IT = FR基准（无证据表明更贵或更便宜）
- DE = FR基准（Agency图片标准Ex≤€0.15比FR IG P25=€0.11更宽松，是Agency放水，不是市场差异）
- TT = IG推算（CPC×0.7 / CPM×0.6 / CTR×1.3，因为FR投放数据无TT placement）
- **无市场溢价系数**：DE×1.45、IT×0.73系数拍脑袋，已废弃。用户原话："别被牵着鼻子走，给客观标准"

## 数据清洗铁律（必须最先执行）
1. **CTR > 20% = 口径异常**：clicks(all)不是link clicks，剔除该placement
2. **clicks > impressions**：clicks口径错误，剔除
3. FR 8场清洗后：FB=37条、IG=42条，共79条有效placement
4. 剔除的8条：SEPTEMBEROCTOBER sheet中CTR 356%/362%/241%/88%(FB) + 437%/544%/376%/63%(IG)

## 档位映射规则
- CPC/CPM（低优）：P25=Excellent, P50=Good, P75=Pass, >P75=Poor
- CTR/ER（高优）：P25(高)=Excellent, P50=Good, P75(低)=Pass, <P75=Poor

## FR 8场分布（清洗后）
- **FB (n=37)**: CPC P25=0.06/P50=0.08/P75=0.10 | CTR P25=5.2%/P50=3.7%/P75=2.9% | CPM P25=2.62/P50=2.99/P75=3.76

## CPC口径陷阱（KOL Organic vs Traffic）
KOL organic投放的sessions可能是自然流量而非付费link clicks。此时CPC会严重超标（€3-11 vs 标准€0.15）。
判定方法：
- 投放目标=Organic KOL → 不判CPC，改用eCPM/ER/播放-粉丝比
- 投放目标=Traffic/Link Click → 正常判CPC
- 无法确定 → 标注"CPC口径不可用"，用eCPM+ER替代
